QuotaSpill

Keep your paid Claude or OpenAI-powered coding agent running when its quota runs out, by spilling over to a free-tier backend only when the real subscription actually fails.

View on GitHub How it works

The gap this fills

Free-tier LLM routers like freellmapi, OpenRouter, and LiteLLM's public routing all solve the same problem: stack a pile of free-tier accounts behind one endpoint and route across them. None of them solve the opposite problem for a developer who already pays for Claude or OpenAI: staying online when a rate limit or monthly cap hits mid-task.

QuotaSpill flips the priority. Your real, paid provider is always tried first. A free-tier fallback, which can be a single provider or a whole local aggregator, only takes over when the primary actually returns a quota error, or when a budget cap you configured is reached. Nothing is silently masked: a bad request or bad API key is relayed to you exactly as the primary sent it.

They pair well together: point QuotaSpill's fallback at a local freellmapi instance, and your paid quota keeps resetting untouched while freellmapi's free-tier catalog absorbs the overflow.

How it works

1Request lands on /v1/messages (Anthropic wire) or /v1/chat/completions (OpenAI wire).
2If a monthly budget cap is already spent, skip straight to the fallback chain.
3Otherwise call the primary. A 429/529 quota-style error moves to the next provider; anything else (400, 401, 403…) is relayed to you immediately, unmodified.
4Streaming responses are piped through byte-for-byte; usage tokens are parsed off the SSE stream on the side, so the dashboard's savings estimate works for streamed answers too.
5Every response carries X-QuotaSpill-Source: primary:<name> or fallback:<name>, and a local dashboard tracks the split.

Quick start

git clone https://github.com/sunilgentyala/quotaspill.git
cd quotaspill
cp quotaspill.config.example.json quotaspill.config.json
cp .env.example .env
# edit .env: set ANTHROPIC_API_KEY / OPENAI_API_KEY, and FREELLMAPI_KEY

node --env-file=.env bin/quotaspill.js start
# dashboard: http://localhost:8787

Honest limitations

  • No cross-wire translation. A chain's primary and fallback must speak the same API shape; Anthropic-to-OpenAI translation isn't implemented.
  • Doesn't extend your real quota. The fallback answers with a different, usually weaker model. It keeps your agent's session alive, not your subscription's token count.
  • Budget caps count requests, not tokens, since that's the metering unit QuotaSpill controls directly.
  • Mid-stream drops aren't recoverable once the primary has already started streaming a 200 response.
  • Single-user, no auth of its own. Meant for localhost, like the fallback services it typically points at.
